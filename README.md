## About

I'm a software engineer based in the Philippines with a product-minded approach
to full-stack development. I work across frontend, backend, data, and delivery
to turn ambiguous problems into clear, maintainable systems.

My current focus is operational platforms, real-time collaboration, and AI
features that reduce busywork. I care about the details users feel, the
boundaries teams depend on, and the engineering practices that help products
evolve.
